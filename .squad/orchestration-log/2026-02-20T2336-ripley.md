## Architecture Summary

**Refkey-first, rendering deferred:** Static helpers are NOT yet rendered through Alloy `<ts.SourceFile>` components. They continue through `loadStaticHelpers()` → TsMorphBridge. Refkey functions establish the stable API contract. Full Alloy migration deferred to Phase 9 to avoid dual-write conflicts.

**Manual imports over auto-imports:** Components use `getStaticHelperFileInfo()` to build manual import statements—pragmatic bridge until Alloy's auto-import resolution is available (Phase 9).

**Refkey namespace isolation:** All static helper refkeys use prefix `refkey("StaticHelpers", category, name)`. Isolated from old framework refkeys, type refkeys, and operation refkeys.
